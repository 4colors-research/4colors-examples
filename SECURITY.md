# Security

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's "Report a vulnerability" button
(Security tab) or by email to [info@4colors-research.com](mailto:info@4colors-research.com) (subject: "Security"). We acknowledge reports within a few
working days.

## If you exposed an API key

Never paste keys into issues, pull requests, notebooks or code. If a key was exposed, revoke it and create a new one
at [account.4colors-research.com](https://account.4colors-research.com/?utm_source=github&utm_medium=examples&utm_campaign=security).
The examples read keys from `FOURCOLORS_API_KEY` or from a file named by `FOURCOLORS_KEY_FILE`.

## Scope

This repository holds examples. Vulnerabilities in the 4colors service or the `fourcolors` package are also welcome
through the same private channel.

# Datasets

No instance data is stored in this repository. Loaders download public sets from their original source, check a
published checksum where one exists, and cache them locally (`~/.cache/fourcolors-examples/`).

Each loader states, in its docstring and in the table below: the source URL, the license or terms, how to cite the
set, and its checksum.

| Set | Source | License / terms | Loader |
|---|---|---|---|
| _none yet_ | | | |

Rules: only sets whose terms allow redistribution of results; cite the authors; never commit the data.

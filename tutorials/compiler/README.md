# Compiler tutorials

Planned, as runnable versions of the docs tutorials:

- **Time budgets for the compiler**: the first answer versus a time budget, and watching better circuits arrive.
- **Compile for your own device**: describe a device as a custom target and compile a large circuit onto it.

Start with [`quickstart/compiler_hello.py`](../../quickstart/compiler_hello.py) and the
[compiler docs](https://docs.4colors-research.com/compiler/?utm_source=github&utm_medium=examples&utm_campaign=tutorials&utm_content=compiler).
